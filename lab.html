OSINT lab in your browser

Real tools compiled to WebAssembly that run inside your browser. There is no server and no third-party connection: the files you open here never leave your computer. Today it includes ExifTool 13.42, the same tool as in our example review.

Guided exercises

  1. Where was this photo taken? Read the GPS and open it on the map. Hint: it is a famous spot in Buenos Aires.
  2. Was the photo edited? Look for the embedded thumbnail. If it exists, extract it on your computer with exiftool -b -ThumbnailImage and compare: if it does not match the image, that is a sign of editing.
  3. What happened to the metadata? This is the same photo re-saved, as when it is uploaded to social media. What is left?
  4. Is it what it claims to be? The file is named .jpg. Check the real type and the warning.
  5. Who wrote the document? Find the author and the software that produced the PDF.

💡 Remember: metadata is a lead, not proof. It can be stripped on upload and forged in seconds.

What about a full virtual machine?

A full Linux inside the browser is possible (emulators like v86), but it would have no network: browsers do not allow direct connections, so tools like Sherlock or Maigret could not query sites. That is why we chose tools compiled for the browser, which really work offline. Tools that need the internet come with the community server (100 and 1,000 ⭐ goals), and later, ready-to-use investigation machines.
