Instalação segura de ferramentas OSINT e de cibersegurança

Muitas ferramentas do diretório não são usadas pela web: são instaladas. São código de terceiros que o OSINTario revisa, mas não audita linha por linha. Este guia explica como instalá-las sem expor seu computador nem seus dados. Cada ficha do diretório com a etiqueta 🧪 leva à sua seção.

⚖️ Instalar não é ter permissão. Escanear, explorar ou interceptar sistemas alheios sem autorização é crime na maioria dos países. Pratique no seu próprio laboratório.

7 regras que valem para todas

  1. Use uma máquina virtualVirtualBox, VMware ou UTM com Kali ou Debian. Nunca instale no computador onde estão seu email, seu banco ou processos reais.
  2. Tire um snapshot antesSe algo der errado, você volta ao estado limpo em um minuto.
  3. Leia antes de executarAbra install.sh e requirements.txt. Desconfie de «curl … | sudo bash» e de binários sem código-fonte.
  4. Baixe da origem oficialO repositório ou site do autor, não um espelho nem um link de comentário. Verifique o hash ou a assinatura se houver.
  5. Sem root, salvo necessidadeUma ferramenta que busca apelidos não precisa de sudo. Se pedir, pergunte-se por quê.
  6. Isole a rede e os dadosRede em modo NAT, sem pastas compartilhadas nem área de transferência com seu computador. Use contas e chaves de API criadas só para investigar.
  7. Feche o caso limpoExporte a evidência com seu hash, anote versão e data da ferramenta e volte ao snapshot.

Kali Linux

A base do laboratório: uma máquina virtual com centenas de ferramentas já instaladas. Comece por aqui. Site oficial ↗

# 1. baixe a imagem para VirtualBox ou VMware só de kali.org/get-kali (Virtual Machines)
# 2. confira se o hash coincide com o publicado no site
sha256sum kali-linux-*-virtualbox-amd64.7z
# 3. importe a VM, entre com kali / kali e troque a senha
passwd
# 4. atualize e tire um snapshot limpo
sudo apt update && sudo apt full-upgrade -y

Sherlock

Busca um apelido em centenas de redes sociais. Site oficial ↗

pipx install sherlock-project
sherlock APELIDO

# sem instalar nada, com Docker
docker run --rm -it sherlock/sherlock APELIDO

⚠️ O mesmo apelido em duas redes é uma hipótese, não uma identidade confirmada.

Maigret

Busca um apelido em milhares de sites e monta um relatório com os dados de cada perfil. Site oficial ↗

pipx install maigret
maigret APELIDO --html

# com Docker; o relatório fica em ./relatorios
docker run --rm -v "$PWD/relatorios:/app/reports" soxoj/maigret:latest APELIDO --html

theHarvester

Reúne subdomínios, emails e hosts de um domínio a partir de fontes públicas. Site oficial ↗

# já vem instalado no Kali
theHarvester -d exemplo.com -b crtsh,certspotter

# a partir do repositório (usa uv)
git clone https://github.com/laramies/theHarvester && cd theHarvester
uv sync
uv run theHarvester -d exemplo.com -b crtsh,certspotter

Subfinder

Enumera subdomínios de forma passiva: não toca o domínio investigado. Site oficial ↗

go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest
subfinder -d exemplo.com -o subdominios.txt

Nuclei

Escaneia um site com templates de vulnerabilidades conhecidas. Site oficial ↗

go install -v github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest
nuclei -target https://SEU-SITE

⚠️ É um escaneamento ativo: só contra sistemas próprios ou com autorização por escrito.

Nmap

Descobre portas abertas e serviços. Site oficial ↗

sudo apt install nmap          # já vem instalado no Kali
# scanme.nmap.org é a máquina que o Nmap oferece para praticar
nmap -sV scanme.nmap.org

⚠️ É um escaneamento ativo: só contra sistemas próprios ou com autorização por escrito.

ExifTool

Lê os metadados de fotos e documentos: data, equipamento, autor, GPS. Site oficial ↗

sudo apt install libimage-exiftool-perl
exiftool ARQUIVO.jpg

# trabalhe sempre numa cópia e guarde o hash do original
sha256sum ARQUIVO.jpg

yt-dlp

Baixa um vídeo com seus metadados para preservá-lo como evidência. Site oficial ↗

pipx install "yt-dlp[default]"
yt-dlp --write-info-json URL
sha256sum *.mp4                # hash do arquivo para a cadeia de custódia

Wireshark

Abre e analisa capturas de tráfego de rede. Site oficial ↗

sudo apt install wireshark     # já vem instalado no Kali
wireshark CAPTURA.pcap

# para capturar sem ser root
sudo usermod -aG wireshark $USER   # saia e entre de novo

⚠️ Capture tráfego só da sua rede ou com autorização.

Conforme o tipo de ferramenta

🧪 Python (pipx ou ambiente virtual)

Cada ferramenta no seu próprio ambiente, assim as dependências não tocam o sistema. Nunca use «sudo pip».

# se estiver publicada no PyPI
pipx install NOME

# a partir do repositório
git clone https://github.com/AUTOR/REPO && cd REPO
python3 -m venv .venv && source .venv/bin/activate
cat requirements.txt        # veja o que instala
pip install -r requirements.txt

🧪 Go (binário único)

Compila para um único arquivo sem dependências. Instale pelo código ou baixe o binário em «Releases» e compare o checksum.

go install github.com/AUTOR/REPO/cmd/NOME@latest

# ou o binário publicado
sha256sum NOME_linux_amd64.zip   # compare com checksums.txt

🧪 Docker (contêiner)

Use a imagem oficial com versão fixa. Não monte sua pasta pessoal nem use «--privileged».

docker run --rm -it -v "$PWD/saida:/data" AUTOR/IMAGEM:VERSION

# serviços com vários contêineres
docker compose up -d      # leia antes o docker-compose.yml

🧪 Só em máquina virtual

O instalador pede sudo, altera o sistema ou a ferramenta é ofensiva (exploração, senhas, Wi-Fi). Use numa VM descartável e só contra sistemas próprios ou com autorização por escrito. Para Wi-Fi é preciso um adaptador USB ligado à VM.

# 1. snapshot da VM
# 2. no Kali muitas já estão nos repositórios oficiais
sudo apt update && sudo apt install NOME

# 3. se só houver instalador próprio, leia-o primeiro
git clone https://github.com/AUTOR/REPO && cd REPO
less install.sh

🧪 Instalador oficial

Programa de desktop ou pacote do projeto. Baixe só do site oficial e verifique a assinatura ou o hash publicado.

sha256sum instalador.exe      # Linux / macOS
Get-FileHash instalador.exe    # Windows PowerShell

Este guia é geral e melhora a cada revisão. Se uma ferramenta precisar de passos próprios, a ficha indica.
