Instalación segura de herramientas OSINT y de ciberseguridad

Muchas herramientas del directorio no se usan desde la web: se instalan. Son código de terceros que OSINTario revisa pero no audita línea por línea. Esta guía explica cómo instalarlas sin exponer tu equipo ni tus datos. Cada ficha del directorio con la etiqueta 🧪 lleva a su sección.

⚖️ Instalar no es tener permiso. Escanear, explotar o interceptar sistemas ajenos sin autorización es delito en la mayoría de los países. Practica en tu propio laboratorio.

7 reglas que valen para todas

  1. Usa una máquina virtualVirtualBox, VMware o UTM con Kali o Debian. Nunca instales en el equipo donde tienes tu correo, tu banco o expedientes reales.
  2. Toma un snapshot antesSi algo sale mal, vuelves al estado limpio en un minuto.
  3. Lee antes de ejecutarAbre install.sh y requirements.txt. Desconfía de «curl … | sudo bash» y de binarios sin código fuente.
  4. Descarga del origen oficialEl repositorio o sitio del autor, no un espejo ni un enlace de un comentario. Verifica el hash o la firma si se publica.
  5. Sin root salvo que haga faltaUna herramienta que busca alias no necesita sudo. Si lo pide, pregúntate por qué.
  6. Aísla la red y los datosRed en modo NAT, sin carpetas compartidas ni portapapeles con tu equipo. Usa cuentas y claves API creadas solo para investigar.
  7. Cierra el caso limpioExporta la evidencia con su hash, anota versión y fecha de la herramienta y vuelve al snapshot.

Según el tipo de herramienta

🧪 Python (pipx o entorno virtual)

Cada herramienta en su propio entorno, así sus dependencias no tocan el sistema. Nunca uses «sudo pip».

# si está publicada en PyPI
pipx install NOMBRE

# desde el repositorio
git clone https://github.com/AUTOR/REPO && cd REPO
python3 -m venv .venv && source .venv/bin/activate
cat requirements.txt        # revisa qué instala
pip install -r requirements.txt

🧪 Go (binario único)

Se compila a un solo archivo sin dependencias. Instala desde el código o baja el binario de «Releases» y compara su checksum.

go install github.com/AUTOR/REPO/cmd/NOMBRE@latest

# o binario publicado
sha256sum NOMBRE_linux_amd64.zip   # compara con checksums.txt

🧪 Docker (contenedor)

Usa la imagen oficial con una versión fija. No montes tu carpeta personal ni uses «--privileged».

docker run --rm -it -v "$PWD/salida:/data" AUTOR/IMAGEN:VERSION

# servicios con varios contenedores
docker compose up -d      # lee antes el docker-compose.yml

🧪 Solo en máquina virtual

El instalador pide sudo, toca el sistema o la herramienta es ofensiva (explotación, contraseñas, Wi-Fi). Úsala en una VM desechable y solo contra sistemas propios o con autorización escrita. Para Wi-Fi necesitas un adaptador USB conectado a la VM.

# 1. snapshot de la VM
# 2. en Kali muchas ya vienen en los repositorios oficiales
sudo apt update && sudo apt install NOMBRE

# 3. si solo hay instalador propio, léelo primero
git clone https://github.com/AUTOR/REPO && cd REPO
less install.sh

🧪 Instalador oficial

Programa de escritorio o paquete del proyecto. Descárgalo solo del sitio oficial y verifica la firma o el hash publicado.

sha256sum instalador.exe      # Linux / macOS
Get-FileHash instalador.exe    # Windows PowerShell

Esta guía es general: mejora con cada revisión. Si una herramienta necesita pasos propios, se indica en su ficha.
